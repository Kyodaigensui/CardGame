# カードゲーム（試作版）

2人用のダイス対戦カードゲームです。**1台の画面を交代で使う対戦**と、**オンライン対戦**（それぞれの端末から、コードで部屋に入る方式）の両方で遊べます。
サーバーは不要で、GitHub Pages のような「ファイルを置くだけ」の場所で公開できます。

## フォルダ構成

| 場所 | 中身 | 追加・変更するとき |
|---|---|---|
| `index.html` | 画面の骨組み（スクリプトの読み込み順もここ） | ほぼ触らない |
| `css/style.css` | 見た目 | 見た目を変えるとき |
| `js/10-cards.js` | **技カード**（`SKILLS`）と追加効果（`FX`） | 技カードを足す |
| `js/20-passives.js` | **パッシブ**（`PAS`）と、その動作（`PK`） | パッシブを足す |
| `js/30-characters.js` | **キャラ**（`POOL1` / `POOL2`） | キャラを足す |
| `js/35-helpers.js` | キャラ生成・ダイス計算の道具 | 通常は触らない |
| `js/40-game.js` | ゲーム本体（戦闘・画面・デッキ構築）。属性 `ATTR`、状態異常 `STN`、効果の条件 `COND` もここ | 属性・状態異常を足す／ルールを変える |
| `js/50-config.js` | オンライン対戦の**中継サーバーの設定** | つながらないときに見直す |
| `js/60-net.js` | オンライン対戦の通信 | 通常は触らない |
| `js/99-main.js` | 起動 | 触らない |
| `tests/run.js` | 自動テスト | 実行するだけ |
| `docs/カードの追加方法.md` | **カード・キャラ・パッシブの足し方** | |

## 自分のパソコンで試す

`index.html` をブラウザで開くだけで、1台での対戦（交代制）が遊べます。
オンライン対戦は、インターネットにつながっている必要があります（通信ライブラリ MQTT.js を読み込むため）。

## GitHub で公開する（GitHub Pages）

ブラウザだけでできます。

1. GitHub にログインし、右上の **＋ → New repository** を選ぶ。名前（例：`cardgame`）を付け、**Public** にして **Create repository**。
2. 作ったリポジトリのページで **uploading an existing file** を選び、このフォルダの**中身すべて**（`index.html`、`css`、`js`、`tests`、`docs`、`README.md`、`.nojekyll`）をドラッグ＆ドロップ。下の **Commit changes** を押す。
   - フォルダごとドラッグすれば、フォルダ構成のままアップロードされます。
   - `.nojekyll` は先頭がドットのファイルなので、見えない場合は、このzipを解凍したフォルダを丸ごとドラッグしてください。
3. **Settings → Pages** を開き、**Source** を **Deploy from a branch**、**Branch** を **main / (root)** にして **Save**。
4. 1〜2分待つと、`https://（ユーザー名）.github.io/（リポジトリ名）/` で遊べるようになります。

Git を使える場合：

```bash
git init && git add . && git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/（ユーザー名）/（リポジトリ名）.git
git push -u origin main
```

## オンライン対戦の遊び方

1. 両者がそれぞれ、ホームで**プレイヤー名**を決め、「デッキ構築」でデッキを作っておく（15枚）。
2. **1人目**：ホームの「オンライン対戦」→ 使うデッキを選ぶ → **部屋を作る**。表示された**コード**（または**招待リンク**）を相手に伝える。
3. **2人目**：招待リンクを開く（コードが入力済みになります）。コードで入る場合は「オンライン対戦」→ コードを入力 → **部屋に入る**。
4. つながると自動で始まります。最初に、場に出すキャラを**両者が同時に**選びます。
5. 行動の決定は、これまでどおり「速度の平均が低い側が先」です。**自分の手番のときだけ**操作でき、もう一方は「相手が行動を決めています」と表示されます。
6. 戦闘は両者の画面で同時に再生されます。ターンの終わりに、**それぞれが「次のターンへ」を押す**と進みます（相手が押すのを待つことがあります）。
7. 決着後は「もう一度対戦」を両者が押すと再戦できます。

## プレイヤー名とデッキ

- 初めて開くと、**プレイヤー名**を決める画面が出ます（12文字まで）。デッキは**名前ごとに2つ**保存されます。
- 名前は、オンライン対戦で**相手にも表示**されます。同じ名前どうしで対戦すると、後ろに「（2）」が付きます。
- ホームの「名前の切り替え・追加・バックアップ」から、別の名前を追加・切り替え・削除できます。
- **保存先は、使っているブラウザの中**です。別の端末・別のブラウザ、またはブラウザのデータを消した場合は引き継がれません。同じ「バックアップ」の「書き出し」で出たコードを保存しておき、新しい端末で「読み込み」すると復元できます。
- パスワード付きのアカウント（どの端末からでもログインできる仕組み）は、サーバーが必要になるため、まだ付けていません。

## しくみと、知っておいてほしいこと

- **方式**：両者のブラウザが「同じ乱数の種」から同じゲーム処理を動かし、手番の**操作の記録**だけを相手へ送って再現します（ロックステップ方式）。手札などのデータそのものは送りません。毎ターン、状態の「指紋」を交換して、ずれていないか確認します。ずれたら画面に出て、対戦を止めます。
- **通信**：**中継サーバー（公開MQTTブローカー）**を経由します。2人が直接つながる方式ではないので、**ルーターやネットワークが別々でもつながります**（以前の直接通信は、同じルーター内でしか安定してつながりませんでした）。中継サーバーを通るのは、操作の記録などの小さなメッセージだけで、通信は暗号化（wss）されます。
- **中継サーバーは無料の公開サービスで、稼働の保証はありません**。`js/50-config.js` に複数を並べてあり、どれかが落ちていても、ほかが生きていれば遊べます。つながらないときは、ここに別のブローカーを足してください。
- **部屋のコードは6文字のランダムな文字列**で、これが宛先の一部になります。コードを知らない人が、他人の部屋の通信を見たり入ったりすることは、まずありません（ただし、公開サーバーなので、機密に当たる内容は流さないでください。流れるのは、デッキの内容・プレイヤー名・操作の記録です）。
- **不正対策はしていません**：相手の手札も、お互いのブラウザの中には存在します（画面には出しません）。開発者ツールを使えば見えてしまうので、**友達同士で遊ぶ用**です。
- **それでもつながらないとき**：学校・会社などで、中継サーバーのポート（8884・8084）が止められていることがあります。別の回線（スマホのテザリングなど）をお試しください。
- **途中でページを閉じたり更新したりすると、その対戦は続けられません**（復帰機能はありません）。
- **バージョンが違うと始まりません**：カードやルールを変えて公開し直したあと、片方が古いページのままだと「バージョンが違う」と表示されます。**お互いにページを更新（キャッシュを無視して再読み込み：Ctrl+Shift+R / Cmd+Shift+R）**してください。GitHub Pages は更新の反映に1〜2分かかることがあります。
- **MQTT.js は外部のサーバー（unpkg）から読み込んでいます**。安定させたい場合は、`mqtt.min.js` を自分のリポジトリ（例：`lib/mqtt.min.js`）に置き、`index.html` の `<script src="https://unpkg.com/…">` をそのパスに書き換えてください。
- **キャラ名・カード名について**：他社の作品に由来する名前や設定を使っている場合は、公開前に、その作品の二次創作・ファンコンテンツのガイドラインを確認してください。

## 自動テスト

Node.js が入っていれば、一番上のフォルダで次を実行できます。

```bash
node tests/run.js
```

データの書き間違い、1台対戦のエラー、**オンライン対戦のずれ（2つのブラウザ役を通信でつないで、毎ターン状態が一致するか確認）**、通信の異常系（バージョン違い・不正なデータ・切断・再戦）を調べます。
カードやパッシブを足したあとに実行すると安心です。`GAMES=300 node tests/run.js` で試合数を増やせます。

## カード等を足したくなったら

`docs/カードの追加方法.md` を見てください。ゲーム本体を直さなくても、データのファイルに1行足すだけで追加できます。
