# カード・キャラ・パッシブの追加方法

ほとんどの追加は、データのファイルに**1行足すだけ**です。ゲーム本体（`40-game.js`）を直す必要はありません。
追加後は、書き間違いがあると**読み込み時にエラー（ブラウザの F12 → コンソール）で場所が分かる**ようになっています。

> **いちばん多い失敗**：配列やオブジェクトの**行末のカンマ**。新しい行を足すとき、**その1行前の行末に `,` を付ける**のを忘れないでください（最後の行は付けても付けなくても構いません）。

## 1. 技カードを足す（`js/10-cards.js`）

`SKILLS` の中に1行足します。

```js
{n:"新しい技",c:2,d:[D('a',3,8),D('d',2,6)]},
```

| 項目 | 意味 |
|---|---|
| `n` | カード名（**他のカード・キャラと重複しない**こと） |
| `c` | コスト |
| `d` | ダイスの並び。`D('a',最小,最大)` ＝攻撃、`'d'`＝防御、`'e'`＝回避 |
| `req:'属性名'` | （任意）その属性を持つキャラだけが使える（`ATTR` のキー） |
| `once:true` | （任意）使い捨て（使うと消滅）。`FX` 側に書く |

**追加効果**は、同じファイルの `FX` に、カード名をキーにして書きます。

```js
"新しい技":{on:[['draw',1]],hit:[['coin',2,'kill']]},
```

- `on`：カードを使った時に起きる効果／`hit`：的中時（カード1回の使用につき、条件を満たした最初の的中で1回）
- ダイスごとの的中時効果は、ダイスの4つ目に書く：`D('a',3,8,[['burn',2]])`
- 効果は `[種類, 数値, 条件(任意)]`

**効果の種類**：`draw`（ドロー）、`cost`（コスト回復）、`heal`（HP回復）、`coin`（感情コイン）、`dmgup`（次ターン与ダメージ+）、`guardup`（次ターン被ダメージ-）、`rollup`（次ターンの全ダイス+）、`atk`（次ターンの攻撃ダイス+）、`burn`/`bleed`/`rupt`/`vib`（火傷・出血・破裂・振動を相手に付与）、`vibex`（振動爆発）、`rolldn`/`vuln`/`dmgdn`（相手の次ターンのダイス値-／被ダメージ+／与ダメージ-）

**条件**（3つ目）：`'kill'`（倒したとき）、`['dmg',8]`（8以上のダメージ）、`['foeHp',10]`（相手の残りHP10以下）、`['selfHp',10]`、`['foeSt','burn']`、`{and:['kill',['dmg',8]]}`。
条件を増やしたいときは、`40-game.js` の `COND` に1行足します。

## 2. キャラを足す（`js/30-characters.js`）

`POOL1`（または `POOL2`）に1行足します。

```js
{name:"新キャラ",title:"肩書",slot:1,hp:35,spd:[2,6],ps:['tough','sharp']},
```

| 項目 | 意味 |
|---|---|
| `name` | キャラ名（重複しないこと） |
| `title` | （任意）名前の下に小さく出る肩書 |
| `slot` | 帰属枠（他のキャラのパッシブを受け取れる数） |
| `hp` / `spd` | 最大HP／速度ダイスの範囲 |
| `ps` | パッシブ（`PAS` のキー）。**先頭が「一番上」**で、帰属カードとして渡されるのもこの順 |
| `at:['属性名']` | （任意）属性（`ATTR` のキー） |
| `size:2` | （任意）場の枠を2つ使う大型キャラ |

`POOL1`/`POOL2` の違いは「初期デッキに入れる最初の5体」にだけ影響します。デッキ構築では、どのキャラも両プレイヤーが使えます。

## 3. パッシブを足す（`js/20-passives.js`）

`PAS` に1行足し、キャラの `ps` に書きます。数値を足すだけのものは、既存の「種類」を使えます。

```js
mypas:{n:'名前',k:'atk',v:2},        // 攻撃ダイス+2
```

**種類 `k` の一覧**は、同じファイルの `PK` にあります（数値型：`spd`/`atk`/`def`/`eva`/`guard`/`debuffup`/`ailmentup`、動作型：`maxhp`/`regen`/`ts`/`catchup`/`killup`/`cardup`/`lowhp`/`startdmg`/`emolv`/`lvbuff`）。
新しい動作が必要なら、`PK` に新しい種類を足します。**フック**（`init`＝戦闘開始/帰属時、`start`＝戦闘開始時、`turn`＝ターン開始時、`speed`＝速度決定後、`kill`＝撃破時、`dice`＝ダイスを振るとき、`lvup`＝感情レベル上昇時）の使い方は、ファイル先頭のコメントに書いてあります。

## 4. 属性・状態異常・条件を足す（`js/40-game.js`）

- 属性：`ATTR` に1行足し、キャラの `at:[…]`、カードの `req:'…'` で使う
- 状態異常・バフの表示：`STN`
- 効果の条件：`COND`

## 5. 足したあとにやること

1. `node tests/run.js`（Node.js がある場合）。データの書き間違いや、オンライン対戦のずれを調べられます。
2. ブラウザで `index.html` を開いて、デッキ構築画面や対戦を確認する。うまく動かないときは F12 → コンソールを見る。
3. GitHub に反映（アップロード／push）する。反映に1〜2分かかります。
4. **オンラインで遊ぶ2人とも、ページを更新（Ctrl+Shift+R / Cmd+Shift+R）**する。更新が違うと「バージョンが違う」と表示されて始まりません（これは、ずれたまま対戦してしまうのを防ぐための仕組みです）。

## 6. ゲーム本体（戦闘のルール）を変えるときの約束

オンライン対戦は「両者が同じ処理を同じ順に動かす」方式なので、次を守ってください。

- **乱数は `R(最小,最大)` / `sh(配列)` / `rnd()` だけを使う。`Math.random()` を直接使わない**（使うと両者がずれて、対戦が止まります）。
- 画面を描くだけの処理（`render` など）が、**ゲームの状態 `S` を変えない**ようにする。
- 手番中の操作（`assign` / `pickTgt` / `redir` / `unassign`）を足すときは、`logOp([...])` で記録し、`netApplyDecide` で再現できるようにする。
- 変更したら `node tests/run.js` を実行する。オンラインの「状態が一致」の項目が失敗したら、どこかで上の約束が破れています。
